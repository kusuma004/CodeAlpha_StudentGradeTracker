# Student Grade Tracker

## Project Overview
The Student Grade Tracker is a console-based Java application that allows users to add student records, view student grades, and calculate grade summaries.

## Features
- Add student names and marks
- Validate student names and marks between 0 and 100
- View all student records
- Calculate grades based on marks
- Calculate average marks
- Find the highest and lowest marks
- Display a summary report
- Exit through a menu option

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner class

## Grade Criteria
- 90–100: A
- 80–89: B
- 70–79: C
- 60–69: D
- 50–59: E
- 0–49: F

## How to Run
1. Install the Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Compile the Java file:
   `javac Main.java`
5. Run the application:
   `java Main`
